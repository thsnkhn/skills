# Skills

Agent skills by Tahseen Kakar.

## Install

Install a specific skill globally for Codex:

```bash
npx skills add tahseen-kakar/skills --skill x-content-writer -g -a codex -y
```

Install from the direct GitHub path:

```bash
npx skills add https://github.com/tahseen-kakar/skills/tree/main/skills/x-content-writer -g -a codex -y
```

## Available Skills

### x-content-writer

Draft, revise, critique, and plan Twitter/X posts, tweets, replies, quotes, and threads using an algorithm-informed content playbook.

Path: `skills/x-content-writer`
