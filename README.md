# Skills

Agent skills by Tahseen Kakar.

## Install

Install a specific skill globally for Codex:

```bash
npx skills add thsnkhn/skills --skill linkedin-writer -g -a codex -y
npx skills add thsnkhn/skills --skill x-content-writer -g -a codex -y
```

Install from the direct GitHub path:

```bash
npx skills add https://github.com/thsnkhn/skills/tree/main/skills/linkedin-writer -g -a codex -y
npx skills add https://github.com/thsnkhn/skills/tree/main/skills/x-content-writer -g -a codex -y
```

## Available Skills

### linkedin-writer

Draft, rewrite, and critique natural LinkedIn posts in a bundled direct builder-operator voice grounded in real work and evidence.

Path: `skills/linkedin-writer`

### x-content-writer

Draft, revise, critique, and plan Twitter/X posts, tweets, replies, quotes, and threads using an algorithm-informed content playbook.

Path: `skills/x-content-writer`
