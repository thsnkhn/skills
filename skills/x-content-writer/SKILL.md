# X Content Writer

## Overview

Use this skill to write Twitter/X content that is clear to the right audience, likely to earn meaningful positive actions, and unlikely to trigger avoidable negative feedback.

The operating model comes from `references/x-algorithm-playbook.md`. Read that reference when drafting a batch, making a content plan, diagnosing performance, or when the user asks for algorithm reasoning. For a single quick post, use the workflow below unless deeper evidence is needed.

## Workflow

1. Identify the user's topic lane, target audience, goal, format, and voice. If one is missing and the request is still workable, make a conservative assumption instead of blocking.
2. Choose the positive action the post should primarily earn: dwell, reply, repost, quote, share, profile click, or follow.
3. Make retrieval obvious: use concrete nouns, entities, category language, and context that tell both humans and the system who the post is for.
4. Write a first line that carries real value or tension for the intended audience. Avoid vague curiosity hooks that disappoint after the click.
5. Deliver the payload quickly: proof, opinion, framework, story, teardown, contrast, practical step, or specific observation.
6. Scan for negative feedback risk: bait-and-switch, outrage farming, spammy CTAs, repetitive formats, unclear media, unsafe phrasing, or audience mismatch.
7. Output ready-to-post copy first. Add a short rationale or checklist only when the user asks for strategy, critique, or variants.

## Format Guidance

For standalone posts:
- Keep one clear point per post.
- Make the post understandable without hidden context.
- Prefer specificity over broad advice.
- End with a line that invites the intended action naturally, not with manipulative engagement bait.

For threads:
- Use a strong first post that stands alone.
- Give each post a distinct job; do not split one weak idea into many posts.
- Keep the thread tight enough that every post earns continued dwell.
- Finish with a useful conclusion, not a generic CTA.

For replies:
- Make the reply self-contained and specific to the parent post.
- Add a useful point, correction, example, or sharper framing.
- Avoid generic praise, link drops, repeated promotional replies, and hijacking unrelated posts.

For quote posts:
- Add an angle that changes, clarifies, expands, or challenges the original.
- Make the quote useful even to someone who only sees the quoted context briefly.

For media-backed posts:
- Use media only when it adds proof, explanation, entertainment, or clarity.
- Ensure screenshots are mobile-legible.
- For video, make the first seconds useful and include visible or spoken context.

## Quality Bar

Do:
- Write for a coherent audience, not everyone.
- Keep posts aligned with a small set of recurring topic lanes.
- Create posts that can earn replies, shares, quotes, profile clicks, and follows, not only likes.
- Make claims concrete enough to be agreed with, challenged, saved, or quoted.
- Use media when it improves comprehension or proof.
- Keep sensitive topics precise, factual, and safe.

Do not:
- Produce generic AI-sounding advice, recycled platitudes, or broad motivational filler.
- Optimize only for likes.
- Keyword-stuff hashtags, cashtags, or topic labels.
- Use rage bait, misleading hooks, or bait-and-switch links.
- Recommend reply spam, duplicate posting, or flooding many similar posts at once.
- Claim guaranteed reach, exact ranking weights, or live algorithm facts from the local snapshot.

## Draft Review Checklist

Before finalizing, check:

- Candidate: Is it clear who this post is for?
- Topic: Does it reinforce a known lane?
- Hook: Will the first line stop the right person?
- Value: Is there a concrete idea, proof, story, data point, or useful opinion?
- Action: Which positive action is this likely to predict?
- Media: Does media add meaning, or is it decoration?
- Safety: Could it trigger mute, block, report, not interested, spam, or safety filters?
- Repetition: Is this too close to a recent post?
- Audience: Is it attracting the people the account should be associated with?

## Output Defaults

When the user asks for content, provide polished post copy. If useful, include 3 to 5 variants with different angles such as contrarian, practical, story-led, proof-led, or reply-bait-resistant.

When the user asks for a plan, provide topic lanes, post concepts, target action, format, and a lightweight measurement note. Track replies, reposts, quotes, shares, profile visits, follows, video retention, and negative feedback clues rather than likes alone.

When the user asks for critique, lead with the highest-impact issue, then provide a revised version.
